# 📍 Onde Encontrar as Configurações de IA

## 🎯 Duas Formas de Acessar

### 1️⃣ Pela Tela Principal (NOVO!)

Na tela inicial do app, você verá um novo card:

```
┌─────────────────────────────────┐
│         [Ícone de Config]       │
│                                 │
│  🤖 Configurações de IA         │
│                                 │
│  Configure Google Gemini AI     │
└─────────────────────────────────┘
```

**Como acessar**:
1. Abra o app
2. Role até o final da tela
3. Toque no card "🤖 Configurações de IA"

### 2️⃣ Pelo Menu "Meus Currículos"

**Como acessar**:
1. Abra o app
2. Toque em "Meus Currículos"
3. Toque no menu (⋮) no canto superior direito
4. Selecione "Configurações"

## 📱 Fluxo Completo

```
Tela Principal
    ↓
[Toque no card "Configurações de IA"]
    ↓
Tela de Configurações
    ↓
[Cole sua chave API do Gemini]
    ↓
[Toque em "Testar" (opcional)]
    ↓
[Toque em "Salvar"]
    ↓
✅ Pronto! IA configurada
```

## 🎨 Visual do Card na Tela Principal

O card de configurações aparece **após** o card "CV Pro Premium" e tem:

- **Ícone**: Engrenagem (⚙️)
- **Título**: "🤖 Configurações de IA"
- **Descrição**: "Configure Google Gemini AI"
- **Cor**: Azul (cor primária do app)

## ✅ Verificação

Após a atualização, você deve ver:

1. ✅ Card de configurações na tela principal
2. ✅ Opção "Configurações" no menu de "Meus Currículos"
3. ✅ Ambos levam para a mesma tela de configurações

## 🔄 Se Não Aparecer

Se o card não aparecer após atualizar:

1. **Feche completamente o app**
   - Não apenas minimize
   - Force o fechamento nas configurações do Android

2. **Limpe o cache do app** (opcional)
   - Configurações do Android
   - Apps → Gerador de Currículo
   - Armazenamento → Limpar cache

3. **Reinstale o app** (se necessário)
   - Desinstale a versão antiga
   - Instale a nova versão
